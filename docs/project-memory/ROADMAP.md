# Очередь и критерии завершения

Обновлено2026-11-18, Europe/Kiev. Статус конкретных SHA — только CURRENT.

1. **Память/передача — выполняется.** Короткий AGENTS, единый индекс/статус,
   стандарты, правила запуска, удалённый WIP; архив всех linkedworktrees с
   HEAD/index/working/untracked/deletions; пробное восстановление и проверка
   скачанных с GitHub байтов. Не завершать по одному локальному tar.
2. **Подводный SPA — реализуется.** Отдельный от ТРЦ/старого CatSPA курорт.
   Довести физический вход (берег/субмарина→лифт/шлюз→сухие проходы), переходы
   уровней, герметичную оболочку, все14зон,84фазы поведения, AI/брони/экономику.
   Уже проверен только in-room массаж+SQLite, не весь маршрут/все процедуры.
   Готовность: нужные реальные кадры/сценарии каждой процедуры, отмена/занятость/
   reload/phone, сравнение с референсом, время кадра/паузы/память, Node22/fullCI/
   liveassets. Пустые платформы или единичный массаж не готовый курорт.
3. **Производительность — очередь.** Актуальный аппаратный отчёт после полной
   загрузки, одинаковые мир/камера/качество/DPR. Полное время кадра, длинные
   паузы/память; не объявлять6секундные Macфризы исправленными по SwiftShader.
4. **Графика воды/дна/растительности — очередь.** Одна общая водная основа,
   физические профили; стабильный релиз — контроль регрессий, CrimsonDesert —
   визуальная цель. Проверять день/ночь, движение, мобильный бюджет.

Архитектурный/художественный редизайн ТРЦ исключён пользователем. Функциональные
проходы опубликованы3914873; будущие изменения должны сохранять их проверки.
Не возвращать старые отменённые задачи и не смешивать SPA с редизайном ТРЦ.
