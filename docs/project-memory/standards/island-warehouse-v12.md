# V12 — единая расширенная лагуна и далёкий Warehouse

2026-11-20: пользователь явно разрешил перекроить берег как угодно. Требование
сохранить кольцо из исходного задания отменено. Водоём должен быть ОДИН огромный;
Warehouse находится в воде и очень далеко от ТРЦ/SPA, как на фото.

Phase1: только география и одна герметичная внешняя стеклянная оболочка с золотым
каркасом, нейтральным основанием и наружной вывеской. Не оборудовать интерьер,
не добавлять Squish/магазины/AI/новый транспорт/экономику. Существующие ТРЦ и SPA
неподвижны и невредимы, включая материалы, комнаты, воду, камеры и механику.
Сохраняются модели/масштаб котов и мозазавра, покупки/ID/координаты/кошельки.

Код — mosasaur-expansion-data.js (план), mosasaur-expansion.js (общий водоём/дно),
warehouse-exterior.js (оболочка), warehouse-habitat.js (ограниченные reef pockets).
Существующая водная поверхность дополняется геометрией с прежними uniform/
material/clock/normal field/probe; новый глобальный shader запрещён. Центральная область
до95% прежнего нормализованного радиуса дна и реальные подходы к зданиям защищены; меняется бывшая кромка
берега. Структуры не масштабируются. Старые данные radii/других островов прежние;
большой overview получает отдельные реальные границы. Детализация должна
загружаться в новом масштабе, не оставлять lowOnly из-за прежнего порога.

Реальное расстояние считать между actual3D boundingboxes зданий, а не centres:
минимум2–3полных ширины Warehouse; текущая цель>=3ширин платформы. Отдельно
проверять отсутствие пересечений с другими островами и бесконечным жилым рядом.
Новые внешние земли пока не вводят отдельную экономику/схему сохранений. Для
затопленных старых оплаченных адресов используются защитные pads. Старые spans
подходов не растягивать на километры через пустую воду. NPC не должны стоять на
удалённом береге: valid прежние координаты сохранившегося сухого участка.

QA: baseline builders/boxes/sourcefreeze, build/targeted/full Node22; реальные
8ракурсов и mobile, каждый имеет exactsource/bundle/hash/параметры камеры.
QA far plane должен включать всю дистанцию до объекта: PNG с обрезанными
зданиями не является valid comparison. Фиксировать неудачные стадии отдельно.
CI/GLSL PASS не равен сходству с референсом или одобрению пользователя.
Mac/iPhone FPS нельзя обещать по SwiftShader. Ссылки на текущую ветку/SHA — CURRENT.
