путь, а не только свободную конечную точку. Все 28 подходов из общественной
зоны и 20 прежних маршрутов проходят тесты. Настоящая игра также проверила
путь туда и обратно к Aroma0 и Cabana4.

На исходниках 4b72f2f native проверка завершена: 16 видов, 11 сухих и четыре

390×844 при DPR2 прошла удержание кнопки движения и освобождение управления.
