# Память проекта Chichi Cat Wizard World

Перед работой прочитай [текущий статус и единственную очередь](CURRENT.md),
затем стандарт затрагиваемой системы:

- [Вода: Crimson Desert, историческая база d6fa805 и общее ядро](standards/water.md).
- [Грунт и растительность](standards/terrain-vegetation.md).
- [ТРЦ: архитектура, жизнь, покупки и сохранения](standards/mall.md).
- [Управление и камеры](standards/controls-camera.md).
- [Решения, ошибки и отклонённые подходы](decisions.md).
- [Правила QA-манифестов и сохранения WIP](evidence-and-recovery.md).

`CURRENT.md` — единственная актуальная точка продолжения. Стандарты содержат
устойчивые требования и архитектуру; решения — причины изменений и отказов.
Старые отчёты `docs/qa/` и исходники остаются первичными доказательствами;
эта карта их связывает, а не заменяет.

**Различай:** реализовано локально → проверено → опубликовано → визуально
одобрено пользователем. Эти состояния не равнозначны. Успешный GLSL/native
тест не доказывает красоту, средний FPS не исключает длинные паузы, а старый
PNG не подтверждает новую правку. Не повышай статус без нового доказательства.

После существенного открытия, изменения, неудачи или публикации обнови
соответствующий стандарт/решение и `CURRENT.md`, сохрани точный код и сведения
о QA в удалённой ветке. Локальный `/workspace` и память чата недостаточны.

До проверенного игрового релиза память находится в WIP-ветке. Если новый чат
открыл старый main, её можно прочитать без изменения текущих файлов:

```bash
git fetch origin codex/ocean-recovery-memory
git show FETCH_HEAD:docs/project-memory/CURRENT.md
```

Не считать main обновлённым этой памятью до фактического проверенного merge.
