- Работающий Memory Foam.

- Звуковые эффекты, если они предусмотрены V19.

## 4. ГЛАВНОЕ ПРАВИЛО ПРОХОЖДЕНИЯ ЭТАПОВ

Используй следующую логику.

Если этап работает на базовом уровне, переходи к следующему.

Если обнаружен некритический визуальный недостаток, зарегистрируй его в трекере и продолжай другие задачи.

Если обнаружен критический дефект, который ломает физический движок, исправь его до продолжения зависимых задач.

Если проблема не блокирует другие материалы, продолжай независимую разработку.

Не повторяй десятки раз один тест без изменения диагностической гипотезы.

После нескольких неудачных попыток:

1. Зафиксируй точный симптом.
2. Запиши результаты диагностики.
3. Определи предполагаемую причину.
4. Предложи альтернативный способ реализации.
5. Сохрани текущий безопасный результат.
6. Переключись на независимую задачу.
7. Вернись к проблеме в следующем проходе.

**Не путай настойчивость с бесконечным повторением одного и того же действия.**

# 5. ОБЯЗАТЕЛЬНЫЕ 12 ЭТАПОВ V19

## PHASE 1 — EXISTING PINK SQUISH

Исправь существующий розовый сквиш, на котором стоит Чичи.

Обязательно реализуй:

- Контакт лап с поверхностью.
- Локальные вмятины.
- Давление тела.
- Изменение формы под нагрузкой.
- Базовое восстановление.
- Синхронизацию персонажа с поверхностью.

Если базовое продавливание работает, переходи к следующему этапу.

Не трать весь цикл разработки на идеальную настройку одной вмятины.

## PHASE 2 — CAT PAW IK

Проверь:

- Четыре точки контакта лап.
- Правильную высоту лап.
- Перенос веса.
- Сидение.
- Ходьбу.
- Прыжки.
- Приземление.
- Отсутствие проваливания.
- Согласованность с движением поверхности.

Не переписывай уже работающую систему ручного приземления без конкретной необходимости.

## PHASE 3 — MEMORY FOAM

Реализуй четыре состояния:

1. NORMAL.
2. PAW PRESS.
3. DEEP COMPRESSION.
4. SLOW RECOVERY.

Приоритет — сохранение отпечатка после снятия нагрузки.

## PHASE 4 — JELLY

Реализуй:

1. NORMAL.
2. COMPRESSION.
3. WOBBLE.
4. RECOVERY.

Обязательно должны присутствовать:

- Локальное продавливание.
- Перераспределение объёма.
- Волнообразные колебания.
- Постепенное затухание.
- Восстановление формы.

## PHASE 5 — SLIME

Реализуй:

1. REST.
2. STRETCH.
3. TWIST.
4. MERGE.

Дополнительно:

- Вязкость.
- Липкость.
- Нити.
- Постепенное утончение при растяжении.
- Закручивание.
- Отпускание.
- Слияние двух масс.

Если полноценное слияние временно не реализовано, используй устойчивую базовую модель с корректным визуальным переходом, сохранив полноценное слияние как незавершённое требование.

Не выдавай имитацию слияния за готовую физическую систему.

## PHASE 6 — CRUNCHY BUTTER

Реализуй:

1. INTACT.
2. COMPRESSION.
3. CRACKS.
4. FRACTURE.

Обязательно:

- Мягкая сердцевина.
- Локальное давление.
- Складки.
- Накопление повреждений.
- Постепенное появление трещин.
- Локальные фрагменты.
- Пластическое изменение формы.

## PHASE 7 — CLOUD

Реализуй:

1. FLUFFY REST.
2. SOFT SINK.
3. WIDE COMPRESSION.
4. SLOW RECOVERY.

Cloud не должен вести себя как Jelly.

Котик должен медленно погружаться в очень мягкую поверхность.

После снятия нагрузки материал постепенно расправляется.

## PHASE 8 — PLAYER INTERACTION

Добавь:

- PRESS.
- HOLD.
- DRAG.
- STRETCH.
- TWIST.
- RELEASE.

Используй существующую систему взаимодействия мышью или касанием.

Не ломай управление камерой.

## PHASE 9 — MULTI-CONTACT

Протестируй:

- Одного котика.
- Двух котиков.
- Несколько отдельных лап.
- Одновременные контакты с разных сторон.
- Перенос нагрузки.
- Одновременные прыжки.
- Восстановление после нескольких воздействий.

Физическая система должна корректно обрабатывать несколько контактов одновременно.

## PHASE 10 — PHYSICS LOD

Внедри:

- Детальную физику активных HERO-объектов.
- Упрощённую физику остальных близких объектов.
- Shader deformation для второстепенных игрушек.
- Статичное отображение дальних коллекций.
- Автоматическое повышение детализации при взаимодействии.
- Отключение ненужных дорогостоящих симуляций.

## PHASE 11 — REFERENCE VALIDATION

Используй предоставленное изображение с пятью материалами и двадцатью физическими состояниями.

Для каждого состояния:

1. Запусти игру.
2. Воспроизведи действие.
3. Сделай реальный скриншот.
4. Сравни форму с референсом.
5. Проверь локальность деформации.
6. Проверь контакты лап.
7. Проверь визуальные материалы.
8. Зафиксируй расхождения.
9. Исправь критические дефекты.
10. Обнови отчёт.

Подготовь сравнительную панель:

**REFERENCE | CURRENT GAME | DIFFERENCES**

Не выдавай концепт-арт за результат реализации.

## PHASE 12 — REGRESSION & FINAL VALIDATION

Проверь:

- Warehouse существует.
- Фасад Warehouse не изменился.
- Координаты Warehouse сохранены.
- ТРЦ не изменился.
- SPA не изменился.
- Котики не повреждены.
- Управление работает.
- Камера работает.
- Ручное приземление работает.
- Физика стабильна.
- Геометрия не взрывается.
- Нет NaN и Infinity.
- Сохранения работают.
- Игра собирается.
- Физика не вызывает недопустимого падения FPS.

- Контактные точки.
- Физические узлы.

- Damage values.

**FIRST MAKE ALL FIVE MATERIALS WORK. THEN MAKE ALL FIVE MATERIALS BEAUTIFUL.**

Проверки безопасности и критических ошибок выполняй на каждом проходе.

Если первая деформация уже работает, не нужно бесконечно повторять тест приземления.
