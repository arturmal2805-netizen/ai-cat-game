# Чичи — мир маленьких чудес

Сказочный 3D-мир на Three.js: 24 острова, 62 предмета магазина и 28 котов-соседей. Чичи выбирает настроение и занятие через Cloudflare Workers AI по кнопке **«Дай Чичи решить самой»**. Игра рассчитана на телефон и компьютер.

Сайт: https://arturmal2805-netizen.github.io/ai-cat-game/

## Чичи и ИИ

Объёмная модель в `public/cat-model.js` создана по фото Чичи: тёплая серо-коричневая шерсть, оливково-золотые радужки с радиальными волокнами, мягкая мордочка, тёмный нос, тонкие светлые усы, высокие уши и толстый сужающийся хвост. Мелкие пряди объединены в геометрию; модель работает без внешних текстур. Три состояния ИИ сохранены:

- `sleep`: закрытые глаза, низкая поза, спокойное дыхание;
- `crazy hungry`: широко открытые глаза, открытый рот, беспокойный хвост;
- `happy`: открытый любопытный взгляд, мягкий наклон головы, спокойная анимация и прогулки.

ИИ получает энергию, голод и комфорт (`happiness`), предыдущее состояние и очищенный снимок доступного мира. Выбирает конкретный `activityId` готового предмета или `friendId` доступного котика, настроение, мысль и занятие: `explore`, `play`, `ride`, `meet`, `party`, `rest`, `eat` или `farm`. Сервер проверяет ID предметов, доступность соседей и совместимость занятия с предметом. Для любого предметного занятия, включая сон, еду и исследование, нужен `activityId`; для встречи — только `friendId`. Свободная локация без физической цели не принимается. Старый `target` теперь определяется сервером по занятию для совместимости сохранений; движение идёт к выбранному объекту. На стартовом острове всегда есть бесплатные подушка у домика и плед с едой. ИИ знает характеры соседей, близость дружбы, описания предметов и последние восемь завершённых занятий. История сохраняется на устройстве и различает собственные решения, ручные команды и демо. Незавершённые постройки в снимок не попадают. Для фермы передаются число созревших и свободных грядок.

Используется `@cf/meta/llama-3.3-70b-instruct-fp8-fast`. Запросы выполняются по кнопке; фоновых AI-запросов нет. Демо явно обозначено. Ручная отправка Чичи на ферму сохраняет её текущее настроение. Кнопки ухода меняют потребности; настроение определяет ИИ. Потребности обновляются раз в 20 секунд в активной вкладке и фиксируются на время приключения.

Для ИИ отдельно поясняются сытость (`100 - hunger`) и усталость (`100 - energy`), чтобы он не путал голод с запасом еды. Температура генерации — 0.1. Для однозначного истощения, крайнего голода и полной бодрости сервер проверяет соответствие настроения факторам. Противоречивое настроение или выбор недоступной/отсутствующей физической цели получают одну корректирующую попытку через ту же модель. Сервер возвращает ответ модели, а повторная ошибка даёт `AI_INVALID_DECISION`; локальный ответ вместо ИИ не создаётся. В смешанных состояниях выбор остаётся за моделью. Проверка реальных сценариев перед публикацией остаётся обязательной.

Чичи дышит, моргает, слегка переводит взгляд, шевелит ушами и хвостом; диагональные пары лап движутся при ходьбе. `setCatMood` плавно переводит существующую модель в новую позу, сохраняя объект и геометрию. При уменьшении движения новая эмоция применяется сразу, без фоновой анимации. Соседи используют облегчённую геометрию и собственные цвета; смена настроения не меняет их размер. Браузер создаёт три портрета из этой же модели. Сборка генерирует GLB с анимациями `MoodLoop` и `Walk`, записывая движения живого рига, включая моргание, уши, челюсть и дыхание. Проверки модели находятся в `test/model.test.mjs`.

## Мир, магазин и управление

24 биома: лунный сад, медовая осень, снежная сказка, жемчужный пляж, лагуна, ведьмин лес, солнечный луг, изумрудная роща, сакура, облачное королевство, карамельные дюны, звёздная долина, драконьи искры, кристальное королевство, сахарный сад, радуга, бамбук, лунные грибы, галактика, кораллы, лотосы, ледяное королевство, остров часовщика и сумерки. Различаются палитры, растительность, декорации, частицы и характерные ориентиры. Открытие каждого биома добавляет свою культуру и соседей; некоторые также открывают сбор ресурсов. Для части поздних биомов нужны собранные урожаи или дружба.

Магазин содержит 62 предмета с 3D-превью, поиском и категориями: игрушки, аттракционы, транспорт, места встреч, украшения и фермерские постройки. Есть эпические, легендарные и мистические горки, водные спуски, карусель, колесо, корабль, ракета, дирижабль, игрушки, библиотека, планетарий и площадки праздников.

Все 24 острова получили отдельные палитры, неровные каменные берега, цветочные сады, извилистые дорожки, фонарики и разные ориентиры: от сакуры и грибных домов до обсерватории, ледяных башен, кораллов и часовщика. Оригинальный прозрачный художественный атлас добавляет подробную листву, пальмы, заснеженные ели и домики. Это обращённые к камере иллюстрации внутри 3D-сцены; рельеф, коты, вода и аттракционы остаются трёхмерными. Если атлас не загрузился, работает геометрическая растительность. Декоративные сады освобождают пространство под размещёнными предметами.

В пляжном биоме находится прозрачная бирюзовая лагуна с 36 разноцветными рыбками; озёра также есть в лунном саду, сакуре, пустыне, водном, коралловом и лотосовом биомах. Вода использует Fresnel, блики, процедурное отражение неба, рябь и световые узоры на дне; это WebGL-шейдеры, а не аппаратная трассировка лучей. Рыбки двигают хвостами и плавниками; водопады стекают с берегов.

Детализация по последнему референсу: вместо кольца деревьев каждый остров имеет отдельную композицию из 2–3 деревьев. Дополнительный прозрачный атлас содержит иву, осенний клён, бамбук, яблоню, кристальную ель и грибное дерево. На земле распределены сотни мелких травяных кустиков, цветов, папоротников и мха; зимой и в пустыне плотность и палитра отличаются. Четыре instanced-группы используют общую геометрию, а ветер считается в вершинном шейдере. Растительность не занимает дорожки, воду и следы построек; при перестановке предмета сады и деревья освобождают место, не меняя сохранённые координаты.

В каждой лагуне добавлен подводный сад: разветвлённые и веерные кораллы, трубчатые формы, морские анемоны и водоросли. Берега пляжа, водного и кораллового биомов украшены коралловыми группами. Световые узоры на воде и дне используют движущиеся нерегулярные ячейки, а прозрачность и цвет меняются от глубины к берегу. Течение и ветер учитывают уменьшение движения. Деревья пока декоративные; лазание и отдых котов на ветках остаются отдельным будущим этапом.

Добавлены шесть горок: «Небесная лагуна», «Петля цветущих снов», «Лунный экспресс», «Грибной серпантин», «Облачная корона» и «Золотая карусель времени». Они имеют движущиеся вагончики, разные маршруты и оформление; у лагуны есть аквариум. Новые горки строятся от 6 до 24 часов. Остальные предметы получили общее оформление цветами и фонариками. Карточки земель показывают сам остров; можно посмотреть закрытый биом до покупки, сохранив ограничения на размещение.

Покупка отправляет предмет в сумку. Выберите открытый остров, поставьте предмет касанием карты, поверните и подтвердите. Предпросмотр показывает допустимость позиции. На компьютере работают стрелки и Escape. Нельзя размещать за краем острова, на другом предмете или основном строении. Нажмите на поставленный предмет, чтобы переставить или убрать его. Перестановка бесплатна. Саму Чичи можно перетащить к игрушке, готовому аттракциону, ферме, месту отдыха/еды или к конкретному котику. Под пальцем появляется подсказка занятия и кольцо цели; отпускание запускает именно показанную цель, даже если сосед успел сдвинуться. Ручные команды не вызывают ИИ и сохраняют текущее настроение. Строящаяся вещь или пустое место не запускают случайное занятие. В мире одновременно допускается 60 предметов.

Новые объекты строятся **от 30 минут до суток**; обычные горки — 4 часа, эпические — 8 часов, легендарные и мистические — 24 часа. На карте видны леса и строительные часы, в карточке — оставшееся время. Таймер использует сохранённый срок готовности и продолжается между визитами. Перестановка его не сбрасывает. Убирать можно готовые объекты; повторное размещение готового предмета не требует строительства. Ферму с урожаем сначала нужно собрать.

С клубочком Чичи играет в отдельную анимированную охоту: толкает лапкой, бежит за катящимся шариком, приседает и прыгает с вытянутыми лапами. Клубок вращается вокруг своего центра; пряжа следует за ним. Реакции накладываются поверх настроения ИИ. При уменьшении движения прыжки и погоня отключаются. После игры игрушка возвращается на сохранённое место; убранный во время занятия предмет отменяет занятие без наград. Чичи катается вместе с движущимся транспортом, следует маршруту горок, играет, встречает соседей, танцует в компании и работает на грядках. После встречи или вечеринки растёт дружба. Соседи — NPC этой игры. Настроения остаются тремя прежними, а реакции на аттракционы дополняют их анимацией и репликой.

Карту можно вращать, приближать, отдалять и переключать в обзор всех островов. На телефоне масштаб меняется двумя пальцами. Детальные острова создаются по мере приближения камеры, статические детали объединены по материалам, а дальние коты заменяются компактными маркерами; на телефоне ограничены разрешение рендера и тени. Магазин использует готовые PNG-превью всех предметов и биомов, поэтому их 3D-сцены не строятся на телефоне при открытии меню. В рабочем checkout без готовых картинок остаётся последовательный рендер с асинхронной компиляцией шейдеров. Пока магазин открыт, карта не отрисовывается в фоне, но игровая симуляция продолжает работать. Появление последних превью не перестраивает сетку магазина и не сбивает прокрутку или выбранную кнопку. Учитывается настройка уменьшения движения. Без WebGL доступны уход, ИИ, магазин и фермерское меню.

Для обновления превью после изменения оформления запустите `node scripts/capture-previews.mjs` в checkout с установленным Playwright и Chromium. При внешней установке можно задать `CHICHI_PLAYWRIGHT_MODULE` и `CHICHI_CHROMIUM`. Инструмент рендерит действующие модели магазина и островов, проверяет ошибки WebGL и сохраняет изображения вместе с manifest в `public/art/previews`. Они коммитятся вместе с визуальными изменениями; обычной сборке и CI браузер не нужен.

## Ферма и котомонеты

Стартовая готовая ферма содержит два созревших урожая. Откройте «Ферму», выберите культуру и засейте свободные грядки. Семена стоят монеты, рост занимает от 3 минут до 6 часов. Созревший урожай собирает Чичи — через ИИ, ручную кнопку или **перетаскивание котика на готовую ферму**. Урожай попадает на склад, затем продаётся за монеты. Повторный сбор и продажа одного урожая исключены. В каждом из 24 биомов открывается уникальная культура.

Пляж и водные острова открывают рыбалку, леса — сбор грибов, магические и кристальные острова — самоцветы, цветущие — пасеку. Ресурсы продаются со склада. У каждого занятия есть сохраняемый срок восстановления.

Дополнительные награды:

- 420 котомонет при создании мира;
- +70 за ежедневный визит, день считается по Europe/Kyiv;
- +60 за каждый полный час, включая отсутствие на сайте, максимум за 24 часа при одном сборе;
- +10 за результативный уход или завершённое приключение, не чаще раза в 10 минут.

Перезагрузка не выдаёт награды повторно. Обратный перевод часов не начисляет почасовой доход. Валюта игровая, без настоящих платежей.

## Сохранение

Покупки, монеты, сумка, расстановка, открытые биомы, стройки, посевы, склад, потребности и дружба записываются сразу в `localStorage`, ключ `chichi-world-v2`. Перед подтверждением изменения запись читается обратно и сравнивается с отправленной. Если запись не подтверждена, изменение отменяется и показывается ошибка. Предыдущая версия хранится в `chichi-world-v2:backup`; она используется, если основное сохранение перестало разбираться как JSON. Старые сохранения получают бесплатную ферму или готовые грядки в сумке.

В меню фермы можно **скачать сохранение** и **восстановить его из JSON-файла**. Сохраняются абсолютные сроки готовности построек и растений, поэтому перезагрузка не перезапускает ожидание.

Прогресс хранится в этом браузере, облачной синхронизации нет. Очистка данных сайта удаляет локальный прогресс; скачанный файл позволяет восстановить его. Котомонеты не являются серверным кошельком: локальные данные можно изменить вручную.

## Разработка и проверки

Node.js >=20, рекомендуется 22.

```sh
npm ci
npm run build
npm test
npm start
```

Сервер слушает порт 3000; можно изменить `PORT`. Для настоящего локального ИИ нужны серверные `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`. Для игнорируемого `.env`: `npm run build && node --env-file=.env server.mjs`. Ключи не попадают в браузер или исходники. Без них доступно демо.

`public/dist/` и `public/models/` — игнорируемые результаты сборки. Приложение нужно собирать перед запуском.

Тесты проверяют AI-контракт, совместимость занятий, геометрию всех предметов, доступность размещения, экономику, повторные награды, таймеры, ферму, сохранения и Worker. Дополнительно проведены браузерные проверки на компьютере и в Chromium с мобильным экраном 390×844 и касаниями: покупка, размещение, стройка после перезагрузки, ручная и AI-ферма, продажа, семена, открытие культур, отказ хранилища, перетаскивание Чичи, большая горка и магазин. AI-ответы в локальных UI-проверках подставляются; реальные ответы Cloudflare отдельно проверяет workflow.

## Публикация

GitHub Settings → Pages → Source: **GitHub Actions**. В **Actions secrets**, не Agents secrets:

- `CLOUDFLARE_API_TOKEN`: Account / Workers Scripts / Edit и Account / Workers AI / Read для нужного аккаунта;
- `CLOUDFLARE_ACCOUNT_ID`: secret либо repository variable.

В Cloudflare должен быть зарегистрирован workers.dev subdomain. Worker использует binding `AI`, токен нужен для деплоя и проверки адреса; в браузер он не сохраняется.

Push в `main` запускает установку, сборку, тесты, Worker, четыре реальных AI-сценария и публикацию Pages с адресом Worker. Проверяются прежние три настроения и решение с доступными занятиями, соседями и грядками. Ошибка ИИ блокирует обновление Pages. Cloudflare использует environment `production`, Pages — `github-pages`. Адрес и результаты находятся в GitHub Actions logs.

Статический workflow Publish Chichi to GitHub Pages доступен вручную; он использует `CHICHI_API_URL` из repository variables или адрес ранее опубликованного сайта. Публичный Worker API не содержит пользовательской авторизации; CORS разрешает фронтенд GitHub Pages. Для контроля расходов применяются настройки Cloudflare аккаунта.
